Audit reports preserve their original historical wording. They are not the
current task list, and resolved findings may remain in an original report as
provenance. Current English entry points are the root
[`README`](../../README.md), [`STATUS_EN`](../STATUS_EN.md) and
[`WORKFLOW`](../WORKFLOW.md).
